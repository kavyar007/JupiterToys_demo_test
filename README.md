# Playwright BDD Automation Framework

## Tech Stack

- Playwright
- TypeScript
- Cucumber
- Page Object Model

## Installation

npm install

npx playwright install

## Execute all tests

npm test:all 

## Execute Contact Validation

npm test -- --tags "@error"  

## Execute Contact Success

npm test -- --tags "@success"  

## Execute Cart Validation

npm test -- --tags "@cart"
